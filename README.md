Ex.No:1 CALCULATOR USING ARITHMETIC OPERATOR  
AIM: 
    To create a calculator using arithmetic operation  
ALGORITHM:  
Step 1:Start the process  
Step 2: Select start => Programs => Microsoft visual studio  
Step 3: It opens a dialog box in that select New project icon and select windows form application & specify the file name .then click OK Step 4: After step 3, It opens a new form along with the project. Add a textbox to read input & display the output 
Step 5:Add buttons for numbers from 0 to 9,decimal point & arithmetic operators (+,-,*,/)and Equal(=) 
Step 6:Add clear and End button to clear the textbox content and exit from the form  
Step 7:All arithmetic operators are binary operator &perform the following operations=>’+’sign click number1(display 1 in textbox),operator(+)and then number 2 followed by click’=’sign will display the output in same text box(added result) 
Step 8 : Repeat step 07 for remaining operator 
Step 9: Stop the process
